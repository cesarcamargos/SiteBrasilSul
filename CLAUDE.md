# CLAUDE.md

## Design Context

Este projeto tem contexto de design capturado pelo skill `impeccable`. Antes de qualquer trabalho de UI/design, leia:

- `PRODUCT.md` — registro **brand**, público-alvo (TI/gestores de infraestrutura), posicionamento (IA de ponta via Azure com NF brasileira), personalidade de marca (confiável, técnica, local) e anti-referências.
- `DESIGN.md` — sistema visual "O Estúdio de Arquitetura": tipografia Fraunces (títulos) + Inter (corpo/UI), paleta terrosa neutra com bronze (#8B6F4E) como acento único, cantos retos em todo o sistema, hairlines no lugar de sombra.

Princípios que guiam qualquer mudança: confiança antes de conversão, fala de especialista (não de vendedor), caminho único até a cotação, visual editorial (não SaaS genérico).
